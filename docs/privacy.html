EXOMIC / PRIVACY

Privacy, stated plainly.

This page describes the privacy model represented by the public Exomic project architecture and this static marketing site.

1. Exomic app data

The project specification describes Exomic as an offline-first financial tracker. Core financial records are modeled for local storage, with Hive boxes used for expenses, subscriptions, saving goals and budget limits.

2. Encryption

The project documentation describes encrypted local storage using an AES-256 key accessed through platform secure key storage on Android and iOS.

3. Network use

The documented core data path avoids external network dependencies, APIs and background synchronization for the local financial data engine. This website itself is a static site and does not include third-party analytics code in this build.

4. Website links

Links to GitHub, documentation or other third-party destinations leave this site and are governed by those services' own policies.

5. Changes

This page may be updated when the product architecture or website implementation changes. The date of your use matters, so consult the repository for the current product implementation.
