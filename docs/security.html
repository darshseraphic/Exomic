EXOMIC / SECURITY

A local engine with explicit boundaries.

A plain-language rendering of the security architecture documented in the Exomic repository.

Local storage

Expense, subscription, savings and budget models are written to local Hive boxes rather than a remote financial database.

AES-256 encryption

The repository describes AES-256 encrypted storage and a 256-bit key sourced from Android Keystore or iOS Keychain Services.

Reactive updates

Riverpod is used to propagate local changes across dashboards so the interface can recalculate dependent values immediately.

Destructive actions

The Console provides a purge action behind a confirmation step, making destructive data clearing an explicit user action.

Verification

Security claims here are summaries of the public project documentation. Review the repository implementation, dependencies and release artifacts before relying on them for a specific threat model.
